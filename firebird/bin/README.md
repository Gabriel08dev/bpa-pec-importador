# Dependências locais do Firebird 1.5

Esta pasta recebe, apenas no computador de operação, os executáveis compatíveis com a base legada:

- `fb_query.exe` — cópia local do cliente de consultas validado;
- `fb_backup.exe` — cópia local da ferramenta de backup validada;
- `fbclient.dll` — biblioteca cliente compatível.

Os binários não são versionados porque são componentes de terceiros. Obtenha-os de uma instalação licenciada e compatível com o BPA usado no ambiente.
